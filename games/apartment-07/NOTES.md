# Apartment 07 · Lost at Home: project notes

Last updated: 7 October 2026. Read this before changing anything. It's written so someone who never saw the original chats can pick up the work.

## What the game is

**Apartment 07 · Lost at Home** is a cooperative escape mystery for 1–4 players in the browser, played top-down.

- **Story:** a child wakes up in their family flat during a storm. The power has failed, a faulty "smart" door controller has locked every internal door, and Mum is in the corridor outside with the repair person. The players solve household puzzles room by room to restore backup power and open the front door. Nobody is in danger: there's no timer, no fail state and no punishment for hints.
- **Genre:** co-op puzzle / escape room / light exploration. It's warm and gentle, not horror.
- **Players:** 1–4 in a private online room (six-letter code). Solo uses the same server.
- **Length:** designed for 30–40 minutes. That estimate has never been checked with real first-time players.

### How to play

1. On the home screen, click "Click anywhere to come inside". This starts the music, because browsers block sound until you interact.
2. Under **New apartment**, type a name and create a room. Share the code or the invite link (`?room=CODE`). Friends join under **Join friends**.
3. The host clicks **Begin the story**.
4. Walk up to small glowing dots, press **E**, read the clues and use items from the shared bag on mechanisms.
5. Restore the backup power, then open the front door. Everyone must walk out together to win.

### The puzzle chain (spoilers; the answers live in `server/content.ts` and `server/engine.ts`)

1. **Bedroom:** read the toy-house drawing, take the stool seat and the four legs, assemble the stool at the high shelf, take the winding handle, then wind the release hatch. Opens the bedroom door.
2. **Hall:** the family photo points to the STAR coat hook. It hides the cabinet key, and the key cabinet holds the living-room and kitchen keys.
3. **Living room** (either order with the kitchen): put batteries from the sideboard into the remote and play the TV recording. Sleep → Eat → Read → Arrive, matched to the diagram numbers, gives study code **2413**.
4. **Kitchen:** the grocery receipt (18/06) mentions the tea tin. Take the fridge magnet and pick TEA in the pantry to get the utility key.
5. **Study:** take the transparent sheet and align it on the floor plan to get the route Hall → Rooms → Entrance. The desk drawer code is **1806** (DDMM from the receipt) and it holds the emergency tool.
6. **Utility:** insert the tool into the console, press Hall → Rooms → Entrance and confirm. Backup power returns and Mum's bedroom unlocks.
7. **Mum's room:** the bedside note points to the HOME suitcase, which holds the override key and the instruction card.
8. **Entrance:** insert the key, set the selector to MANUAL, then pull the handle. Everyone walks out to win.

## Tech overview

- **Client:** Vite + TypeScript + Phaser 3 (`src/`). The menus and panels are plain HTML/CSS layered over the Phaser canvas.
- **Server:** Node + Express + Colyseus 0.16 (`server/`). It's authoritative for doors, items, puzzle progress, locks on mechanisms, hints, chat and pings.
- **Shared:** map geometry, collision, line-of-sight and types (`shared/`). The client and server both use it.
- **Art:** `public/art/apartment-cover.png` (home screen) and `public/art/furniture-atlas.png` (furniture sprites). Both were generated by the AI tool that made the original base. Floors, walls, windows, characters and doors are drawn in code (`src/art.ts`, `src/scene.ts`).
- **Sound:** 100% synthesised with the Web Audio API in `src/audio.ts`. There are no audio files.
- **Fonts:** Libre Caslon Display / Libre Caslon Text / DM Sans from Google Fonts, with system fallbacks when offline.

## Done and working

### From the original base
- Online rooms with six-letter codes, up to 4 players, 2-minute reconnect grace and a 20-minute empty-room lifetime.
- The full puzzle chain above, a shared bag, a shared notebook, a three-step hint system per puzzle, chat, pings and a character creator (skin, hair, outfit, accessory).
- Engine tests (rules, both branch orders, 1/2/4 players) and network tests (real WebSocket clients walking the whole apartment).

### Added in the overhaul (7 Oct 2026)
- **Movement rewrite.**
  - Your character now moves on your screen straight away (client-side prediction), with easing on starting and stopping, and a camera that leads slightly in your walking direction.
  - The server validates every reported position (`GameEngine.position` in `server/engine.ts`): no faster than sprint speed, no crossing walls or closed doors. If a move is rejected, the server sends `correct` and the client snaps back.
  - Old `move` input messages still work, and the tests use them.
  - Other players are smoothed with frame-rate-independent interpolation.
- **Shift to sprint.** Walking is 150 px/s and sprinting 250 px/s (`WALK_SPEED` / `RUN_SPEED` in `shared/types.ts`). Sprinting adds a dust trail and a slight lean.
- **New lighting.**
  - The old hard-edged GeometryMask was replaced with a soft "lantern" light map, drawn at half resolution on a 2D canvas and shown on a second camera so zoom doesn't distort it.
  - Rooms you've visited stay dimly visible. Windows let in a little storm light, and the whole flat brightens when backup power is restored.
  - Teammates you can see carry a small light.
  - Occasional lightning flashes with thunder; this can be turned off in Settings.
  - **Root cause of the old "lights glitch":** the visibility polygon mixed angles in 0..2π with `atan2` angles in −π..π, so the shape was traced twice and stray dark wedges appeared. All angles are now kept in (−π, π].
- **Windows fixed.** The old code stamped a window at the same spot in every room. It landed on the bedroom bed's headboard and sometimes on inside walls. Windows are now defined per room in `WINDOWS` (`src/art.ts`): only on outside walls, clear of furniture, with frames, sills, rain on the glass and curtains. The bedroom window is centred above the bed.
- **Doors** swing open with a glow and an unlock sound. Closed doors show a pulsing lock light.
- **Home screen overhaul.**
  - A splash gate that draws the "07" logo.
  - Animated letter-by-letter title, rain streaks and beads on the glass, lightning, floating dust motes and mouse parallax on the cover art.
  - A server-status dot.
  - Main menu (New apartment / Join friends / Your explorer / Music & sound / How to play) with sliding panels.
  - Six-box room-code input with paste support.
  - Explorer customiser with tabs, turn left/right buttons, an animated walking preview and "Surprise me".
- **Music:** six procedural tracks you can pick on the home screen or with the ♫ button in game. The choice is saved in the browser. There are separate Music / Rain & storm / Effects volume sliders and a mute.
  1. Rain on the Window: lo-fi piano
  2. Little Explorer: music box
  3. Quiet Hallway: ambient
  4. Midnight Kitchen: jazzy Rhodes
  5. Backup Power: warm synth arpeggio
  6. Home Again: piano. It plays automatically on the win screen.
- **Sound effects:** footsteps (faster when sprinting), pickups, page turns, unlocks, pings, right/wrong chimes, thunder and win jingle.
- **In-game polish.**
  - Big animated room cards when you first enter each room.
  - A "WHAT NOW" goal tracker driven by the server (`state.objectives`), with "Done: …" toasts.
  - Stacked animated toasts.
  - Item and clue pop-ups that fly into the Bag or Notebook button.
  - A floating "E" bubble over the nearest object.
  - Ping rings in the world, plus edge-of-screen arrows when the ping is off screen.
  - Chat unread badge, door progress pips and an animated lobby code.
  - Combination dial for code locks, clickable item picker (replaces the old dropdown), shake on wrong input.
  - Settings with toggles (names, lightning, all sound) and the full key list.
  - Floating-lights ending screen.
- **Tests:** 14 engine tests, including new ones for position validation and objectives, plus the 2 network tests, all pass. The network "escape" test had a bug, also present in the original code: the bots froze once the game was won, before reaching their last waypoint. It now stops walking once the phase is `won`, and its pathfinder keeps a 1-pixel margin from furniture.

## Planned or discussed, not built

- **Hosting for friends over the internet.** The game needs a long-running Node/WebSocket server. A static host like Vercel alone is not enough, unlike Pixel Peek and Liar's Call. The `Dockerfile` and README "Hosting" section describe the setup:
  - Deploy the server somewhere that supports WebSockets.
  - Set `CLIENT_ORIGIN` on the server.
  - Build the client with `VITE_SERVER_URL=https://your-server`.
  - Put `dist/` on a static host.

  The user hasn't chosen a host yet.
- **Checking the overhaul on the user's own laptop.** It was only verified in a headless test browser, which ran at about 3 fps with software rendering. Real feel (speed, light, music) still needs a human check. The music has never been heard by a person.
- **Mobile / touch controls.** The game is desktop and keyboard only.
- **More chapters or maps.** The engine is built around one map (`shared/map.ts`) and one content file. A second chapter needs its own map, content and action handlers.

## Known bugs and limitations

- **Performance unknown on weak GPUs.** The fog canvas is re-uploaded as a texture every frame (half resolution). If it stutters, lower `FOG_SCALE` in `src/scene.ts` or update the fog every other frame.
- **Fonts need internet.** They load from Google Fonts. Offline, system fonts are used and the layout still works.
- **Winning saves "Home Again" as your track.** `sound.set({ track: 'home' })` on the win screen also stores it as the saved preference.
- **No Shift sprint in chat.** Movement keys are ignored while any text input is focused. This is deliberate.
- **Server restarts end rooms.** Restarting the server clears all rooms, and it runs on a single instance only.
- **Leftover file on the laptop.** There's a stray `zibeP6is` file in the user's local `apartment-07` folder from a failed zip attempt. It's not part of the project and can be deleted.
- **Dev-only test hook.** `window.a07` exposes the scene, state, room and sound for automated tests. It only exists in `vite dev` (`import.meta.env.DEV`) and isn't in production builds.

## Decisions and why

- **Client-predicted movement with server validation** instead of server-only movement. The original moved players only on the server at 20 Hz and nudged the local player toward it, which caused rubber-banding. Validation (speed cap plus a sampled wall check) keeps cheating out.
- **Soft canvas light map instead of a Phaser GeometryMask.** The mask was hard-edged and glitched at corners and doorways, and it hid wall tops. The light map also allows "remembered rooms", window light and lightning.
- **Procedural Web Audio music** instead of audio files: no downloads, no licensing questions, and tracks can be tweaked in code. Six moods give the player a choice, as requested.
- **The look stays warm and storybook,** not horror: a dark teal night palette, gold accents and serif titles, matching the existing cover art.
- **The splash "click to come inside" gate** exists because browsers block audio until the first interaction, so the music can start immediately after it.
- **Kept the original puzzle content** and server rules unchanged, apart from adding `goal` text to each puzzle for the tracker.
