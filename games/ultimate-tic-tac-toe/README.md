# Ultimate Tic Tac Toe

Nine small tic-tac-toe boards make one big board. The cell you play inside a small board decides which small board your opponent must play in next. Win three small boards in a row to win the game.

- **Modes:** local 2-player, vs computer (Easy, Medium, Hard), online with a 4-letter room code (PeerJS / WebRTC, no game server).
- **Seven themes** (Neon Cyberpunk, Paper & Pencil, Dark Minimal, Retro Arcade, Ocean Calm, Forest, Light), each with its own colours, fonts, board and mark style, particles and sound pack.
- **Extras:** interactive tutorial, undo / redo, hints, move history and replay, optional turn timer, scoreboard across rematches, stats and achievements, custom names and symbols, keyboard play, phone-friendly layout.

Static site, no build step. See [`HOW_TO_RUN.md`](HOW_TO_RUN.md) to run, test and deploy it and [`NOTES.md`](NOTES.md) for how it is built and what is left.
