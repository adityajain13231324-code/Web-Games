How it works

From “let's play” to playing in a minute.

  1. 1

    Open a game

    Tap any “Play” button. Pixel Peek and Liar's Call work on phones and laptops. Apartment 07 needs a desktop browser.

  2. 2

    Make a room

    Pick a name and create a room. You get a short code and an invite link.

  3. 3

    Share the code

    Send it over WhatsApp or anywhere else. Friends join from their own device.

  4. 4

    Play and rematch

    Nobody installs anything. When it ends, hit rematch and go again.
