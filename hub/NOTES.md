# Web Games hub: project notes

Last updated: 7 October 2026.

## What it is
A static landing page linking to Pixel Peek, Liar's Call and Apartment 07. Files: `index.html`, `style.css`, `script.js`, `favicon.svg`, `img/`.

## Done
- Overhaul of the first draft (CSS-drawn fake game art) to real screenshots of each game in browser frames, plus how-it-works, about, share/SEO tags, favicon, mobile layout, reduced-motion support.
- Live on Vercel at https://randomwebgames.vercel.app; GitHub Pages workflow (`.github/workflows/hub-pages.yml`) also deploys a copy to https://adityajain13231324-code.github.io/Web-Games/.
- Absolute `og:image`, `og:url` and canonical URL.

## Planned / not done
- No custom domain bought yet (currently randomwebgames.vercel.app).
- Add a game card when a fourth game ships.

## Known issues
- Pixel Peek screenshot is one frame of a random round; fine to retake.
- Fonts load from Google Fonts.
